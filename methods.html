Tournament normalization — context-honest

Per-tournament z: every feature z-scored within its tournament — 2018 block and 2022 block separately. μ_2018, σ_2018 and μ_2022, σ_2022, then z=(x-μ)/σ, clip ±4.

Z = [] for each tournament t in {WC2018, WC2022}: block = X[idxs[t]] μ = mean(block, axis=0) σ = std(block, axis=0); σ[σ==0]=1 Z[idxs[t]] = (block-μ)/σ Z = clip(Z, -4, 4)

Rationale: raw per-90 drifts by era (VAR, press intensity, 5-sub rule in 2022). Without per-tournament norm, a 2018 volume player is punished vs 2022 baseline. Context-honest = 0 means “avg for that World Cup.” Exactly mirrors hoops era-z but for tournaments. Makes Mbappé 2022 vs 2018 peers comparable fairly.

PCA(3) map inside file: C = Z-mean(Z), SVD, P = U[:,:3]·S[:3], minmax to [0,1] for 3D starfield.

Why not global z? — honest trade-off

What we lose

  • Absolute goal rise 2018→2022 is erased in z-space (0 by definition per tournament). We show it in Trends via raw shares, not z.
  • Cross-tournament similarity is style-relative, not raw-volume absolute — intentional for fair guessing.
  • GK excluded — their 16-d breaks (0 shots, 0 pressures).
Plainly:
per-90 = per 90′ played. z = σ above tournament mean. 0=avg in that WC. context-honest = never compare vs other WC mean. mask not needed here — pitch open data complete for qualified (unlike hoops tracking pre-2013).

MTNN v1.1 — 3 towers → 24-d L2

3 sport-agnostic families → ResidualTower → gated fusion → L2 embedding → archetype 8 + profile 16 heads. ~low-params, heavy dropout, weight_decay 1e-3 for small-data honesty.

FAMILIES (from build_features.py) attacking: [GOALS,XG,FINISHING,ASSISTS,KEY_PASSES_P90,CROSSES] passing_control: [PASSES_CMP_P90,PASS_CMP_PCT,PROG_CARRY,DRIBBLES,FOULS_WON] defending_duel: [PRESSURES,TACKLES,INTERCEPTIONS,RECOVERIES,FOULS_CONV] Input d_in per family → cat [x·m,m] → 2·d_in (m=1 complete here, but keeps hoops shape) ResidualTower: 2d_in→32 LN GELU → 16 + skip(2d_in→16) → LN d_tower=16, dropout 0.0–0.2 GatedFusion: towers stack [3,16] → gate = sigmoid(Linear(16→1)) → attn = Softmax(Tanh(Linear→Linear)) mixed = Σ tower_i * attn_i * gate_i (3→16) + ctx_emb 8-d (n_ctx up to 11) → cat 24 → 64 GELU LN Dropout → 24-d → L2 normalize Heads: arch 8 = Linear(24→8) CE on k-means labels profile 16 = Linear(24→16) MSE recon supcon position DEF/MID/FWD con_w=0.5 InfoNCE Temp 0.07 on L2 z ~ low-K params • ONNX-ready 3 towers = hoops 17 towers scaled to soccer; same ResidualTower shape, same gated+attn fusion.

Honest caveats, provenance, what we don’t know

Caveats

  • No telemetry — difficulty is model estimate computed offline from embedding geometry, not measured solve-rates. We state it in game footnote & stats card. Fame prior = none.
  • Difficulty slope 2.5 lifts in-band 35.7%→71.6% on uniform, 61%→92.9% on real MTNN; still honest but tuned.
  • No StatsBomb 360 / freeze-frame tracking — only open-data events (shots, passes, duels, carries, pressures). No xT, no line-breaking model.
  • Position from lineups, not Wyscout role — wing-backs may swing DEF/FWD depending on minutes. Tactical shift = relabel, not sub.
  • Clustering K=8 seeded reproducible but subjective; names = centroid top-2, not scouting report.
  • Match end = latest Half End period≤4; extra-time periods included, shootout excluded. 95′ fallback.
  • Chimera fused vector never existed in real WC.
